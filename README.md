Smart Electricity Usage Analyzer

Project Overview

Smart Electricity Usage Analyzer is a web-based project that helps users calculate electricity consumption and estimate electricity bills for household appliances.

Features

- Calculate monthly electricity usage for a single appliance.
- Analyze multiple appliances at the same time.
- Calculate monthly electricity bills.
- Estimate yearly electricity expenses.
- View saved appliance history.
- Clear appliance history.
- Validate user inputs.
- Display electricity-saving tips.

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Java
- Database: SQLite
- Deployment: Render
- Development Tool: Visual Studio Code

Calculation

- Monthly Units = (Power in Watts × Usage Hours per Day × 30) / 1000
- Monthly Bill = Monthly Units × Electricity Rate per Unit
- Yearly Bill = Monthly Bill × 12

How to Use

1. Open the Smart Electricity Usage Analyzer website.
2. Enter the appliance name, power consumption, usage hours, and electricity rate.
3. Click Analyze to calculate monthly consumption and cost.
4. Add appliances and use Analyze All Appliances to calculate combined usage.
5. Use View History to view saved records.
6. Use Clear History to clear saved records.

Project Purpose

The purpose of this project is to help users understand electricity consumption, estimate electricity expenses, and encourage efficient electricity usage.
